How to do this on your device: ( YOU RE WELCOME)

First off, it needs a solid GPU for optimal results. If your device is not very high-performant, the project will run but at a lower fps.

- Clone the open-source repo hacksider/Deep-Live-Cam . It is pretty easy to find, it got to #1 repository of the day
- For Windows, follow the README instructions, it works perfectly fine
- For Apple silicon (which is my device as well), I had trouble , therefore I used a smaller model called inswapper_128.onnx to make it run smoother. 

Also when you do the run command, add --keep-fps in the command, like this: python run.py --keep-fps 
In the end of the command do not forget the execution provider, according to the README file.

Advice: Keep Many Faces , Fix Blueish Cam and Face Enhancer toggles OFF. They impact the performance if you do not have a high-performant GPU.
