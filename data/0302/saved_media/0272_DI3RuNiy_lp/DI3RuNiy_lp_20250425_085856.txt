Channel C 欠薪｜連續兩天沒內容更新　近 30 員工被拖欠 $66 萬薪金
全文：https://bit.ly/4jrFXXW
網媒 Channel C 僱主早前被指涉「詐騙」「百分百擔保特惠貸款」被捕， 據了解，Channel C 約 29 名編輯部員工，已被拖欠約 66 萬元的底薪等，網站自周三（ 23 日）起，已暫停更新。知情人士指，原僱主被指未能償還款項，被新投資者啟動接管程序， Channel C 員工每月薪金開支約 47萬元，但新投資者暫只願每月付十萬元，以維持 Channel C 運作。香港記者協會主席鄭嘉如表示，有收到 Channel C 員工有關欠薪的勞資查詢，想知道有何保障等。
Channel C 的母公司 Artview Production Limited，其董事在本月 16 日，被警方商業罪案調查科拘捕，指他們涉詐騙、串謀詐騙政府的「百分百擔保特惠貸款」。據了解， Artview Production Limited 的戶口，至 23 日仍被凍結。Channel C 編輯部約 29 位員工，被拖欠月薪、強積金供款等，涉款約 66 萬元，有員工被拖欠薪金三個月。大部分員工，被拖欠強積公供款約六個月。
知情人士指，Channel C 的原僱主，早前將部分股權，抵押給一位投資者，換取注資。新投資者最近以原僱主無法還錢為由，啟動接管 Artview Production Limited 的程序。由於員工被欠薪多時，據了解，Channel C 現時 29 名員工都已停工、休假或離職。翻查 Channel C 的網站及社交媒體，自 23 日起，至今都沒有更新內容。知情人士指，債權人想 Channel C 繼續運作，Channel C 員工的月薪及強積金開支約 47 萬元，但債權人只願每月支付十萬元，聘請少量員工運作，及不會進行直播報道。
《集誌社》記者先後到Channel C位於葵涌宏達工業大廈的舊址，以及另一個被指為新辦公室、位於同一條街的美華工業大廈。
兩個辦公室門外均被貼上公司註冊處的「委任接管人或經理人通知書」，內容提到Channel C母公司 Artview Production Limited，被一名姓戴（音譯：Tai）的人士接管，生效日期為4月23日（周三）。
另有由一間名為JL Investments Capital Limited的公司，張貼有關Artview Production因欠債而需將公司押抵的告示。
《集誌社》就 Artview Production 欠薪情況，向勞工處查詢指，處方傍晚回覆指，根據《僱傭條例》，僱主必須在工資期屆滿後的七天內支付工資，如僱員被拖欠工資或對其僱傭權益有疑問，可到勞工處勞資關係科查詢，處方會提供適切協助。惟未有提到是否有收到相關投訴。
